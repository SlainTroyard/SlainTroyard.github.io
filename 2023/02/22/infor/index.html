Overleaf 快速入门

Overleaf 是目前最常用的在线 LaTeX 协作平台，无需本地安装，仅通过 Web 端访问：https://www.overleaf.com/

功能要点

  • 多人实时协作编辑与编译 LaTeX
  • 在线版本历史回溯，支持离线版本下载
  • 通过共享链接邀请协作者（可设为只读或可编辑）
  • 提供源码（Code）与可视化（Visual）双编辑模式

一般步骤

  1. 登录 Overleaf
  2. 左侧为源码编辑区，右侧为编译预览区（支持自动 / 手动编译）
  3. 在关键节点用 Menu → History 的 Labels 给版本命名，如 240115_1701_Jifeng 或 240115_1701_Jifeng_before-submission

注意事项

  • 适当做离线备份：Menu → Download → Source (.zip) 或 PDF
  • 参考文献 BibTeX 建议从 DBLP 或 Google Scholar 获取
  • 大段离线编写前，注意告知其他合作者，避免合并冲突

协作写作最佳实践（基于意见反馈）

基于意见反馈的协作，指文字由编辑者负责修改、由评注者负责提出意见或建议（不直接参与修改）的模式，主要用于文章基本成型之后。

协作流程示例

  1. 原文：This is One apple.
  2. 评注者提出意见：This is One apple. \annotator{Change One into an.} → 编译后绿色显示 Tom: Change One into an.
  3. 编辑者修改并回复：This is an apple. \annotator{Change One into an.} \editor{Done.} → 同时显示绿色评注与红色回复
  4. 评注者确认：This is an apple.（确认无误后删去双方评注）

注意：editor 不要修改或删除 annotator 的文字，并需对评注逐条回复；annotator 可以修改 editor 的文字，并在确认后删除双方评注。

日常工具列表

下面按用途整理常用工具，已更新失效链接并补充现代替代品。标「可选」的可按需取用。

论文写作

  • 在线 LaTeX 协作：Overleaf（见上文，仅 Web 端）
  • 本地 LaTeX（可选）：编辑器推荐 VS Code + LaTeX Workshop 插件（亦可用 Sublime Text）；发行版推荐 TeX Live
  • 参考文献管理：Zotero（开源，配合 Better BibTeX 导出 .bib）或 JabRef

笔记与协作

  • 笔记 / 知识库：Notion、Obsidian（本地 Markdown）、语雀（替代已停服的有道云笔记、一起写）
  • 思维导图：XMind（官方站，替代经销商 xmindchina.net）

项目与代码管理

  • 代码托管：GitHub（开源 / 公开项目）；Gitee 或 Bitbucket（非公开 / 保密阶段项目）
  • 项目管理：WorkTile，或轻量看板 Trello / GitHub Projects

远程与控制（可选）

  • 远程控制：TeamViewer（Windows 下载）、ToDesk 或 向日葵

学术论文检索

搜索引擎与数据库

  • Google Scholar
  • Semantic Scholar（AI 辅助，含语义引用分析）
  • arXiv（预印本）
  • Google / Bing / 百度学术
  • IEEE Xplore / ACM Digital Library / SpringerLink / ScienceDirect

文献关系与追踪

  • Connected Papers（可视化论文关系图）
  • ResearchRabbit（文献追踪与推荐）
  • DBLP（计算机文献库）。例如 ICSE 2017 会议录 icse2017；按作者检索 jian zhang

会议 / 期刊排名

  • CCF 推荐目录（中国计算机学会）
  • CORE Conference Ranking
